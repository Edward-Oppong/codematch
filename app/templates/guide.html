Master Guide: How Everything Works

From setting up your browser button to mathematical advantage betting — every metric, tool, and concept explained in plain English.

The Core Principle of CodeMatch:

CodeMatch is not a tipster and never predicts match scores. It is an honest mathematical auditor that uses SportyBet's own live odds and underlying probabilities to reveal what a bet really costs, how much house margin is being extracted, and how to structure positive-expectation bets.

1. Setting Up the CodeMatch Bookmark Button

SportyBet blocks servers from downloading their odds directly. To keep the app 100% private and working forever, fetching happens right inside your own browser through a simple bookmark.

How to add it (1-minute setup):
  1. Make sure your browser's Bookmarks Bar is visible (Ctrl + Shift + B on Chrome / Edge).
  2. Go to the Sync / Import page.
  3. Click and drag the black CodeMatch button directly onto your bookmarks bar.
  4. Done! You now have the CodeMatch button installed.
How it works in practice:
  1. Whenever you press any "Fetch with CodeMatch button" in this app, SportyBet opens in a new tab.
  2. On that SportyBet tab, simply click your CodeMatch bookmark.
  3. A small dark box appears in the bottom corner showing the fetch progress.
  4. Once it says "Done", return to CodeMatch and your data is waiting for you!

Privacy & Security: The bookmark only communicates directly with your own CodeMatch server using a private one-way key. It never sees your password, credit card, or account balance.

2. The Hunt — Finding True Value

Why Singles Beat Accumulators (The Maths)

Every leg you add to an accumulator multiplies the bookmaker's house cut against you. A single bet with a 5% margin returns 0.95 per 1 staked. Combine 10 of those same "safe" legs into a parlay and your expected return drops to:
0.95 × 0.95 × 0.95 ... = 0.95¹⁰ = 0.60 per 1 — a guaranteed 40% loss to the house over time. Professional syndicates and sharp bettors almost exclusively bet singles on low-margin markets. This is not a strategy; it is arithmetic.

Value Singles Scanner (Hunt → Value Singles)

The scanner analyzes all saved fixtures to isolate selections where SportyBet keeps the absolute smallest margin (typically under 5%, returning 0.95+ per 1 staked).

  • Focus Market chips — filter to Handicap, Corners, Bookings, Half-Time, GG/NG, Double Chance, Totals, or Stats picks only.
  • Min Return (Back per 1) — set e.g. 0.95 to only show picks where SportyBet keeps under 5%.
  • Tick picks → "Make booking code" — sends selected picks straight to SportyBet and creates codes instantly.

Where SportyBet Keeps Least (Hunt → Where Sportybet keeps least)

Shows the average house margin per market type (Goals, Corners, Bookings, Handicap, etc.) and by league. Use this to understand which market categories are cheapest on SportyBet before you pick selections. The Build Slip from Lowest-Margin Markets card automatically assembles a code from picks in markets below 10% margin at a target odds you set.

One Pick Per Game (Hunt → Leagues → One pick per game)

Builds an optimized accumulator using exactly one selection per fixture across the leagues and dates you choose. Set a Target Odds (e.g. 3.00) and it finds the combination of picks that hits those odds while having the highest possible mathematical chance of winning — never guessed.

Choose the Bet, Find the Teams (Hunt → Leagues → Choose the bet, find the teams)

The reverse approach: you pick the market type first (e.g. "Handicap" or "Corners Over 9"), and it shows you every team where that bet is available. Useful when you already know what kind of bet you want but not which game to apply it to.

Odds Steam & Line Movement Tracker (Games → Odds Steam)

Odds do not move randomly — they move because high-volume betting syndicates are placing large sums of money. When odds drop rapidly (e.g. 2.10 → 1.85), that is called Odds Steam. The market is correcting because sharp money identified value. The Steam Tracker shows you exactly which selections have moved, by how much, and in which direction (Steam = dropping, Drift = rising). Re-fetching leagues regularly gives you more data points to compare.

Odds Zones

Picks are categorized by their odds range so you understand their probability profile:

  • Very Short (< 1.10): Near-certain in bookmaker's view, but yields almost zero return while still carrying tail risk.
  • Lower Risk (1.10 – 1.49): Double chances, heavy home favorites, over 1.5 goals.
  • Medium (1.50 – 1.99): Even-match outcomes, Both Teams to Score, Draw No Bet.
  • Higher Risk (2.00+): Outright draws, underdog victories, exact scores.

3. Slip Lab — Auditing & Code Surgeon

What is a "Code" in CodeMatch?

A booking code is the alphanumeric string SportyBet generates when you save a slip (e.g. AB12CD). Anyone can load it on SportyBet to place the same bet. CodeMatch stores these codes and calculates the true mathematical profile behind each one.

How to Get Codes Into CodeMatch

  • Code Hub — fetches trending public codes from SportyBet's own Code Hub feed. Tap the "Fetch Code Hub" button on the Slip Lab page, click CodeMatch in your bookmarks bar, and all current codes appear automatically.
  • Paste your own — type or paste any booking code into the "Paste a code" box on the Slip Lab page. It fetches the legs from SportyBet and audits them instantly.
  • Built by CodeMatch — codes created using the "Make booking code" buttons across Hunt / Leagues are automatically saved here with their full audit.

The Chance Hero & Dot Grid

When reviewing any code, the top hero displays the true joint probability as "1 in N" (e.g., 1 in 315) alongside a visual grid of 100 or 1,000 dots. Only the green dots represent wins. Seeing 3 green dots out of 1,000 immediately conveys the true difficulty of a 15-leg accumulator that "looks safe".

Accumulator Toxicity Grade (A through F)

Every code is assigned a Toxicity Grade based on the compounded margin SportyBet takes:

  • Grade A (>0.90 return): Low drag. Bookmaker takes <10% of total stake.
  • Grade B (0.80 – 0.90 return): Moderate drag. Typical for 2–3 sharp legs.
  • Grade C (0.65 – 0.80 return): High drag. Bookmaker takes 20%–35%.
  • Grade D (0.45 – 0.65 return): Severe drag. House margin consumes up to 55%.
  • Grade F (<0.45 return): Toxic. SportyBet takes >55% of your stake before the matches even start!

Code Surgeon & Batch Audit

Code Surgeon scans accumulators and identifies individual "toxic legs" that carry excessive house margin (>9% cut on that single market). It offers two operating modes:

  • Single Code Surgery (Slip Lab → Review Code): Highlights toxic legs in that specific slip, proposes lower-margin alternatives (e.g. Draw No Bet instead of risky 1X2 outcomes), and recalculates odds and joint probability side-by-side.
  • Batch Code Surgeon (Slip Lab → Batch Code Surgeon): Audits all saved codes simultaneously across your entire database without clicking on individual fixtures. It surfaces every code with Grade C, D, or F toxicity, isolates every toxic leg across the board, and lets you generate surgical replacement booking codes in a single click.

Custom Parlay Generation Algorithms

CodeMatch includes four mathematical generation algorithms for structuring accumulators with positive mathematical rigor rather than guess-work:

  • Max Chance (Greedy Joint Probability): Solves a multi-fixture knapsack to maximize \(\prod P_i\) while hitting your target total odds. It greedily selects the highest-probability outcomes from independent fixtures.
  • Min Toxicity (Compounded Margin Minimizer): Minimizes the compounded bookmaker house edge \(\prod (1 - m_i)\). Ensures SportyBet's extraction is strictly bounded (often sub-10% total drag).
  • Fair Value Maximizer: Selects picks with the highest ratio of true implied probability relative to quoted price, maximizing Expected Value (EV).
  • Balanced Banker + Value Optimizer: Anchors the parlay with high-probability "bankers" (80%+ chance) and completes the target odds with lowest-margin secondary value legs.

Code Hub — "Best Right Now" & Shared Fixtures

The Best Right Now panel ranks all open codes that haven't started yet by their Back per 1 (highest return first). The Built from fixtures they share panel finds games that appear in multiple popular codes and builds a code from just those shared fixtures at a target odds — useful for seeing what the market is collectively backing.

Fixtures Across Codes (Slip Lab → Fixtures across codes)

Shows every match that appears in 2+ of your saved codes side-by-side. If 5 different Code Hub codes all pick "Home Win" on the same game, that's a signal worth investigating. Buttons let you tick the safest, most popular, or common-ground pick on each fixture and generate a new code.

4. Results Settlement — Finished Matches & Predictions vs. Reality

Pulling Results for Finished Matches

When matches have concluded or odds are no longer live, CodeMatch allows you to pull final scores directly using the CodeMatch bookmark button. Whether an event was imported as part of a booking code or from a league scan, CodeMatch tracks its kickoff time:

  • Automatic Detection: Any match with kickoff > 2.5 hours ago lacking a scoreline is automatically flagged on the Games and Results pages.
  • One-Click Fetch: Pressing "Fetch final scores with CodeMatch button" sends a fetch request to SportyBet to retrieve the actual full-time and half-time scorelines.
  • Direct Game Inspector: Visiting any individual match page (/game/<event_id>) displays a prominent 🏁 Final Score banner once settled, along with outcome pills (✓ Won / ✗ Lost / Void) on every market option available for that fixture.

Automated Settlement Logic Across Market Families

CodeMatch evaluates final scorelines using deterministic mathematical parsers across all standard football market families:

  • 1X2 & Match Result: Evaluates home goals vs. away goals (Home Win, Draw, Away Win).
  • Totals & Over/Under: Evaluates total match goals against lines (Over 0.5, 1.5, 2.5, 3.5, 4.5, Under lines).
  • Both Teams to Score (GG / NG): Settle GG if both home > 0 and away > 0; settle NG if either team is held to nil.
  • Double Chance: Evaluates compound outcomes (1X, X2, 12) against final result.
  • Halves & Half-Time: Evaluates HT results and 1st/2nd half totals when half-time score data is present.
  • Handicaps & DNB: Applies goal spreads or pushes on exact draws.
  • Manual Fallback: Non-score markets (e.g., corners, bookings, player props) can be settled manually in the Legs to mark by hand table with full undo support.

5. Track — Staking, Bankroll & Longevity

Recording a Bet

After placing a code on SportyBet, record it on the Track page (or from the code's review page using the "Record this bet" button). Enter the code and your stake. The app automatically calculates Kelly-recommended stakes once you set your bankroll.

The Kelly Criterion

The Kelly Criterion is the mathematically proven formula for maximizing long-term bankroll growth while preventing bankruptcy. It sizes your stake proportionally to your perceived edge:
Fraction = (Prob × Odds − 1) / (Odds − 1)
Because bookmaker odds estimates are imperfect, CodeMatch defaults to Quarter-Kelly (0.25). Quarter-Kelly drastically reduces volatility and drawdown while capturing ~75% of the theoretical growth rate. Full Kelly grows faster in theory but can wipe out your bankroll on a bad run.

Setting Your Bankroll & Kelly Fraction

On the Track page, set your total betting bankroll (e.g. ₦5,000). Every Value Singles pick and code review will then show an exact recommended stake. Set your preferred Kelly fraction — Quarter is recommended for most users.

Monthly Limit

Set a monthly stake cap. The app warns you at 80% and again at 100% — it won't stop you, but the warning is a bankroll discipline tool.

Account Longevity Shield & Anti-Detection

If you consistently win or bet like an algorithm, bookmaker risk management bots flag and restrict your account. The Longevity Shield protects you in three ways:

  • Anti-Detection Rounded Stakes: Instead of betting algorithmic exact decimals (e.g. ₦14.37), CodeMatch suggests natural recreational numbers (e.g. ₦15.00 or ₦20.00) that don't trigger profiling.
  • Market Diversity Warning: Alerts you if more than 60% of your bets concentrate in a single market family. Bookmakers flag single-market specialists.
  • Withdrawal Advisor: Recommends skimming profits when total net return surpasses +50% of starting bankroll. Withdrawing resets bookmaker profiling.

Closing Line Value (CLV)

The closing odds (the odds right at kick-off, after millions in sharp bets have entered the market) represent the most efficient estimate of true probability. If you consistently place bets at odds higher than the closing price (CLV > 0%), you possess positive mathematical expected value regardless of individual win/loss variance.
Formula: CLV % = (Your Placed Odds / Closing Odds − 1) × 100%
Professional sharp bettors measure their edge entirely through CLV, not win rate. A losing month with positive CLV is still proof of a good process — variance is temporary, edge is structural.

Personal Calibration Engine

Rather than blindly trusting SportyBet's stated probabilities, the calibration engine tracks your actual settled win rate against SportyBet's stated chances by market family, with a 95% Wilson confidence interval. Each family shows:

  • Your win rate vs. SportyBet's stated chance for that market
  • Edge vs SB — positive means you're winning more than their pricing predicts in this market
  • 95% CI — the confidence interval; narrow = reliable signal, wide = need more data
  • Status pill: Beat Bookmaker (significant positive edge), Underperforming, Tracking Stated, or Sample < 50

Calibration becomes meaningful after ~50 settled legs per market family. With 200+ legs it is statistically robust.

Did SportyBet's Chances Come True? (Calibration Table)

Every settled leg in your saved codes grouped into chance buckets (e.g. 50%–60%). If SportyBet's odds are accurate, your actual win rate in each bucket should land inside the "Expected Range." Consistent deviation above the range in a bucket means you are finding value in that probability zone.

Legs to Mark by Hand

Goals settle automatically when a final score is imported. Bookings, Corners, Player Props, Goalkeeper saves and other non-score markets cannot be settled from the final score — they appear in "Legs to mark by hand." Click Won / Lost / Void to settle them. Marked one wrong? Open the code's review and press Undo next to that leg.

Code Hub Track Record

Tracks every Code Hub code that has finished — played or not — as if 1 unit was staked on each. This tells you whether popular public codes perform better than SportyBet's own stated probabilities predict. If popular codes had inside knowledge, their wins would consistently exceed the expected range.

{# ─── 7. GLOSSARY ─── #}

7. Complete Metric Glossary

TermMeaning
Back per 1 (Expected Return)How much money comes back on average per 1 unit staked. 0.95 = 95 kobo back per ₦1 (5% house edge). A return above 1.00 would mean positive expected value — extremely rare and usually a temporary pricing error.
House Margin / OverroundThe cut the bookmaker takes. Calculated as (1.0 − Return per 1) × 100%. A 5% margin means SportyBet keeps 5 kobo of every naira wagered, on average, in this market.
Stated ChanceThe true probability SportyBet assigns to an outcome, extracted from the odds after the margin is removed. If the odds are 2.00 and margin is 5%, the stated chance is roughly 47.6% (not 50%).
Fair OddsWhat the odds would be with zero margin: 1.0 / Stated Chance. If stated chance is 50%, fair odds = 2.00. If SportyBet offers only 1.90, they are pricing in margin.
Market Margin (mkt_kept)The average margin across all selections in that market for that specific game. A 4% market margin means SportyBet keeps 4% from that market's total action on that game.
Joint ProbabilityThe combined chance all legs in a code win simultaneously: P1 × P2 × ... × Pn. The more legs, the lower this gets. A 10-leg code at 70% each has joint probability 0.70¹⁰ = 2.8%.
Toxicity Grade (A–F)Overall rating of how much margin a code carries in total. Grade A = code gives back >90% of stake. Grade F = SportyBet keeps >55%. Reflects the compounded margin of all legs together.
Toxic LegA single selection in a code where SportyBet keeps >9% margin on that market. Code Surgeon highlights these for removal or replacement.
Push / RefundSelections like Draw No Bet or Over 2.0 goals that refund your stake if a specific result occurs. The chance shown is of winning outright — not the refund case.
Odds ZoneBroad category for the odds level: Very Short (<1.10), Lower Risk (1.10–1.49), Medium (1.50–1.99), Higher Risk (2.00+). Used for filtering and the margins table.
SteamRapid shortening (dropping) of odds driven by sharp high-volume syndicate wagering. Indicates smart money backing that side.
DriftLengthening (rising) of odds — money is backing the other side, or team news has weakened confidence in this outcome.
CLV % (Closing Line Value)(Placed Odds / Closing Odds − 1) × 100%. If you bet at 2.10 and the game closes at 1.90, your CLV is +10.5%. Positive CLV is the statistical hallmark of winning bettors. It proves edge independent of short-term luck.
Expected P&LWhat your bets should return mathematically, based on CLV. Diverges from Realized P&L in the short run; they converge over hundreds of bets.
Realized P&LWhat your bets actually returned — the cash in and out.
Empirical EdgeYour actual win rate minus SportyBet's stated chance, in percentage points. Positive = you are winning more than their pricing predicts in that market family.
Wilson CI (95%)The 95% statistical confidence interval for your actual win rate given your sample size. A CI entirely above SportyBet's stated chance = genuine edge. A wide CI = need more data.
Kelly FractionThe fraction of full-Kelly stake you use. Quarter-Kelly (0.25) = 25% of optimal bet size. Drastically reduces ruin risk while keeping ~75% of theoretical growth rate.
Sample < 50Fewer than 50 settled legs in that market family — calibration is statistically unreliable. Normal early on; shrinks as more legs settle.
Tracking Stated50+ bets settled, win rate aligns with SportyBet's stated chance. No significant edge or underperformance detected yet — expected for most markets.
Common Ground PickA pick on a game that covers (contains or implies) the picks chosen in several other codes. E.g., "Over 1.5 goals" covers both "Home Win" and "Away Win" in many score combinations.
Code HubSportyBet's public feed of trending community booking codes. These are not tips — they are popular user-submitted codes. CodeMatch audits them for toxicity and win probability.
Target OddsThe minimum total odds you want your code to reach. The optimizer finds the combination of picks that hits this target while maximizing the win probability.
Stacked picksThe simplest possible code — just the most likely pick on every game. Usually lower odds but higher win chance than the optimized code. Shown for comparison on the Leagues page.

8. Deployment — Run CodeMatch on a Server (Cloud Deployment)

⚠️ Why Vercel / Netlify / Cloudflare Pages won't work

These platforms are designed for static sites and serverless functions that start fresh on every request. CodeMatch uses a persistent SQLite database (data/codematch.db) that grows with your usage. Serverless environments delete the filesystem after every request — your database would vanish. Vercel also has a 50 MB function size limit; the Python dependencies alone exceed this.

What you need: a platform that runs a persistent process (like a long-running server) and keeps files between requests. All four options below do this.

✅ Option A: Render.com (Free tier available)
  1. Push the project to a free private GitHub repository.
  2. Log in to render.com → New + → Web Service.
  3. Connect your repo. Render reads render.yaml automatically.
  4. Add a Persistent Disk: mount path /data, size 1 GB.
  5. Set env var CODEMATCH_DATA_DIR=/data.
  6. Click Deploy. Live at https://your-name.onrender.com.

Free tier sleeps after 15 min of inactivity (cold start ~30s). Paid starter ($7/mo) keeps it always-on.

✅ Option B: Railway.app (~$2–5/mo)
  1. Push to GitHub. Sign in at railway.app.
  2. New Project → Deploy from GitHub repo.
  3. Railway uses the Procfile automatically.
  4. Add a Volume, mount at /data.
  5. Set env var CODEMATCH_DATA_DIR=/data and CODEMATCH_ALLOWED_HOSTS=*.
  6. Your app is live immediately with always-on containers.

Railway charges by CPU + RAM usage. A personal CodeMatch instance costs ~$2–$5/month.

✅ Option C: Any Linux VPS (DigitalOcean, Hetzner, etc.)
  1. SSH into your server. Clone the repo and cd into it.
  2. Run: pip install -r requirements.txt
  3. Start: gunicorn run:app --bind 0.0.0.0:5000 --workers 2 --timeout 120 --daemon
  4. Point a domain to your server's IP. Done.

Hetzner CX11 (€3.29/mo) is more than enough for personal use. Full disk persistence, full control, cheapest option long-term.

✅ Option D: Local network (share with your phone, free)
  1. Find your PC's local IP: run ipconfig in Command Prompt → IPv4 Address (e.g. 192.168.1.5).
  2. Start CodeMatch with CODEMATCH_ALLOWED_HOSTS=* python run.py.
  3. On your phone (same Wi-Fi), open http://192.168.1.5:5000.
  4. Your phone can now use CodeMatch without installing anything.

Requires your PC to stay on. Free. No data leaves your home network. Good for testing before cloud deploy.
